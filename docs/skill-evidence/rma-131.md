# Skill evidence: RMA-131

Which `frontend-vue`, `frontend-js` and `meta` skill rules applied to which window file in RMA-131, and what each changed. Evidence for RMA-128.

How the skills were used: the agent that did the work read each `SKILL.md` as its spec at the start; the skills were not invoked through the Skill tool, so this table records rules applied, not automatic triggers. The tools in `npm run check` enforce the rules that have a tool form.

| Skill | Rule | File | Change |
|---|---|---|---|
| frontend-vue:tooling | ESLint, Prettier, Stylelint and vue-tsc from the templates | `eslint.config.js`, `stylelint.config.js`, `.prettierrc.json`, `tsconfig.json`, `package.json` | Configs copied from `references/`; pinned dev dependencies; `typecheck`, `lint`, `lint:style`, `format`, `check` scripts |
| frontend-vue:tooling | `npm run check` gates a merge from the pre-push hook | `.githooks/pre-push` | `npm run check` runs before the docs and review gates |
| frontend-vue:tooling | Turn a rule off only with a comment in the config | `eslint.config.js`, `stylelint.config.js` | `no-undef` off, `id-length` exceptions, `base.css` ignored, each with its reason |
| frontend-vue:tooling | `build` type-checks first | `package.json` | `build` is `vue-tsc --noEmit && vite build` |
| frontend-vue:sfc-conventions | `<script setup lang="ts">` only | all 23 `web/src/**/*.vue` | Every component converted to TypeScript |
| frontend-vue:sfc-conventions | Props and emits typed with the generic form | all components with props or emits | Runtime `defineProps({...})` and `defineEmits([...])` replaced with `defineProps<{...}>()`, `withDefaults`, `defineEmits<{...}>()` |
| frontend-vue:sfc-conventions | `defineModel` for two-way state | `components/Segmented.vue`, `components/Feed.vue` | `modelValue` prop plus `update:modelValue` emit became `defineModel`; the feed view binds with `v-model` and `setFeedView` is gone |
| frontend-vue:sfc-conventions | Templates stay declarative | `components/Todos.vue`, `components/StatusBar.vue` | Inline `ui.showDone = !ui.showDone`, delete and open-as-app calls moved to named functions |
| frontend-vue:sfc-conventions | Full names | `components/*.vue` | `w`, `g`, `r`, `t`, `x`, `c`, `l`, `d`, `e` loop and handler names spelled out; the `FeedItem` component import is `FeedItemRow` beside the `FeedItem` type |
| frontend-vue:composables-vueuse | VueUse first; no `addEventListener`, `setInterval` or `localStorage` in components | `components/Island.vue`, `components/RecentlyDone.vue`, `components/SheetPage.vue` | `useLocalStorage` for `wt-collapsed` and `wt-recent-open`; the sheet watches the shared `dark` instead of a `matchMedia` listener |
| frontend-vue:composables-vueuse | VueUse first | `store.ts` | `useLocalStorage`/`useSessionStorage` for `wt-ws`, `wt-feed-view`, `wt-mode`; `useEventSource` for the stream; `useNow` with a 30 s `useIntervalFn`; `useEventListener` with `useDebounceFn` for the window size |
| frontend-vue:composables-vueuse | VueUse first | `backdrop.ts`, `App.vue`, `components/AiButton.vue` | `useEventListener` with `useDebounceFn` for resize, `onKeyStroke('Escape')`, `refAutoReset` for the copy state |
| frontend-vue:composables-vueuse | One instance per concept | `scheme.ts` (new) | One `usePreferredDark` for the store, the backdrop and the sheet, replacing three `matchMedia` listeners |
| meta:reuse-first | Walk the ladder, record the rung chosen | `docs/adr/0002-vueuse-in-the-window.md` | One row per candidate: VueUse (rung 3) for storage, scheme, stream, clock, listeners; platform (rung 2) kept for the clipboard and the rail's drag, SortableJS (rung 4) rejected with its reason |
| frontend-vue:component-architecture | Search before building, a component used by one parent stays beside it | `components/` | No new component; layer folders (`features/`, `ui/`) not introduced, see the report |
| frontend-vue:testing | One command before a merge | `package.json` | `npm test` is the last stage of `npm run check`; tests stay on `node:test` with Node's type stripping |
| frontend-js:conventions | Braces on every control structure, full names, arrow functions | `web/src/**/*.ts`, `web/src/**/*.vue` | ESLint `curly`, `id-length`, `func-style`; single-line `if (x) return;` bodies braced; `S` renamed `snapshot`, `j`/`m`/`h`/`q`/`li` and similar spelled out |
| no-code-prose:policy | A comment is a pointer or a short doc block | `store.ts`, `scheme.ts`, `Island.vue`, `RecentlyDone.vue`, `Rail.vue` | New comments are one line each and say why (storage format kept, ADR pointer) |
