# Window texts: one catalog through vue-i18n

**Owner:** the window. **Code:** `web/src/i18n/`. RMA-342.

## What it does

Every text a user sees in the window comes from one English catalog, so a translation is a second
catalog of the same shape and nothing else.

- `web/src/i18n/en/<section>.ts` holds one section of the window, named after its feature folder
  (`status`, `your-move`, `settings`, …) or `common` for texts the `ui/` primitives share.
- `web/src/i18n/en/index.ts` only assembles the sections into the `en` tree. A key is
  `<section>.<group>.<name>`, for example `status.update.reload`.
- `web/src/i18n/index.ts` creates the one `vue-i18n` instance (Composition API, `legacy: false`) and
  exports `useText()` for components and `text()` for plain modules, both made by one `bind` over vue-i18n's `t`. Both take a `TextKey`, the union
  of every leaf path of the English catalog, so a missing or mistyped key fails `npm run check`.
- Parameters are named: `{version}`. A plural is `one | many` with the count passed as the third
  argument: `t('feed.newCount', { count }, count)`.
- `@intlify/vue-i18n/no-raw-text` in `eslint.config.js` refuses a literal visible text in a `.vue`
  template, attributes `title`, `placeholder`, `aria-label`, `data-tip`, `label`, `alt`, `note`,
  `tip` and `text` included. Punctuation and numbers alone are allowed.
- Data from the sources (titles, names, comment bodies) is never a catalog entry; it stays a value.
- `@` and `|` are message syntax: write a literal `@` as `{'@'}`, and use `|` only between the forms of a plural.
  `test/i18n-catalog.test.mjs` renders every message and fails on either.
- A formatted part of a sentence, such as a bold workspace name, goes through `<i18n-t keypath="…">` with a
  named slot, so the sentence stays one message.
- Constants in plain modules (`SERVER_DOWN` in `web/src/lib/problems.ts`) are read once at load; changing the
  locale reloads the page.
- The `core` section holds the texts of the store and of `web/src/lib/`. ADR 0016 records the library and its size.

## Not covered

Texts the server writes (rule `next` steps, notifications, error messages from the API) are not in
the catalog.
